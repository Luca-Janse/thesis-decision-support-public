TAPIR Decision-Support Tool for Grid Constraints

This repository contains the decision-support tool developed for my thesis on dealing with electricity-grid constraints. The main deliverable is an Excel-based tool that combines load data, station forecasts and stakeholder criteria to compare possible solution pathways for local grid congestion.

## Decision-support tool

The tool compares four pathways:

- grid reinforcement;
- battery storage with an Energy Management System (EMS);
- a Group Transport Agreement (GTO) or other collective flexibility solution;
- postponing, exiting or taking no action.

For each case, the tool brings together village electricity-demand patterns, holiday-period peaks, station capacity and forecasts, ATC stress, critical hours, flexibility potential and reinforcement timing. It then applies a transparent multi-criteria assessment from the perspectives of both the grid operator and the company. The result is a case-specific ranking of the solution pathways, together with the supporting evidence, assumptions and uncertainties.

The workbook contains two main sheets:

- **TAPIR Tool** – the user-facing dashboard where a case can be selected and the results are presented;
- **public inputs** – the underlying datasets, weights, scores, formulas, case-specific adjustments and validation notes.
